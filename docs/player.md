# Player 操作

## 打开与播放

打开或拖入视频、音频、图片；右键可打开文件夹或网络链接。`Ctrl+O` 打开媒体，`Ctrl+P` 加载 VPY。图片和网络视频不执行 VS 滤镜。

底栏提供播放、逐帧、关键帧、前后文件、时间/帧号输入和倍速。普通视频拖动进度条可预览，松开精确定位并恢复原状态；BD 松开后只提交最终定位，见 [蓝光](bluray.md)。帧号修改后按 Enter 或移开焦点提交。

进退一帧会暂停播放并移动到相邻画面，再按播放可继续；直通模式按当前画面的时间戳定位，长视频无需从头扫描。直接输入绝对帧号在未建立对应索引时仍可能需要较长等待。

| 操作 | 快捷键 / 鼠标 |
| --- | --- |
| 播放/暂停 | `Space` |
| 切换全屏 / 退出全屏 | `Enter` 或 `F11` / `Esc` |
| 输入/输出与运行信息 | `Tab` |
| 短跳转 | `←/→`，默认 ±1 秒，设置中可改帧/关键帧 |
| 较大跳转 | `Ctrl+←/→` 默认 ±10 秒，`Ctrl+Alt+←/→` 默认 ±60 秒 |
| 切换图片 | `←/→`，同目录名称排序 |
| 滚轮 | 视频默认音量，可改鼠标锚定缩放；图片缩放，Shift+滚轮平移 |

## 直通、增强与补帧

D3D11/Jinc 和无预设原画使用 3FP 直通，不建立 VS 索引。右键“图像处理”分别选择“上采样滤镜”“第二上采样滤镜”“下采样”。主滤镜中的 Anime4K 六档归在一个子菜单，常规算法单列；第二上采样默认 Jinc (Anti-Alias)，独立于下采样。RTX VSR 开启时提示并改用 D3D11 主直通。Full/Lite 均支持这三段；Lite 不执行任意 VPY 或补帧组合。

内置 Anime4K 使用原生 HLSL；修改过的 VPY 或不兼容着色器保留原 GLSL。231/915 个库条目已预编译；归档里的源文件和配套字节码一起按需提取，不要求每次重新转换。不支持的 COMPUTE、CHROMA、OFFSET 等语义仍明确拒绝或回退。

原始高度 ≥2160p 时禁用内置 Anime4K，Jinc/D3D11 保持可选。渲染设置完整列出八档，单击选择起始档位、勾选参与自动切换，D3D11 必选；Tab 与底栏显示实际生效链路。自定义 VPY 不受此内置限制，需自行评估资源。

“VapourSynth 预设”只显示用户与社区预设。用户说明来自 Renderer 预设管理的备注；开发者说明由 `vpy/preset-descriptions.json` 的 `builtin/文件名.vpy` 键填写。程序只补缺失的空键，保留已写说明，不内置推荐文案。

完整便携版的说明文件位于 `VS-GUI-Full/vpy/preset-descriptions.json`。只修改冒号右侧双引号内的说明，例如 `"builtin/Anime-0-CNN-Enhanced.vpy": "这里写你的说明"`；保留左侧路径、双引号与条目间逗号，保存为 UTF-8。保存后重新打开右键菜单即可读取。开发运行读取 `build/mingw-release/vpy/preset-descriptions.json`，这是另一份文件。

Full“图像处理 → 补帧”提供 Jinc/D3D11 自动入口以及 RIFE、RIFE 半宽高、MVTools HQ/LQ 的固定组合。渲染设置用 Jinc/D3D11 两排复选框分别控制自动补帧参与档位；未勾选的档位会跳过，到最后一档仍超载时显示提示。旧配置的补帧起始档位会转换为从该档起参与。关闭补帧后恢复 Anime 自动超分。单文件 Player 提供内置原生 Anime4K、Jinc/D3D11 和自定义着色器，不执行任意 VPY 或 RIFE/MVTools。

“超分补帧组合”的前三项先 Anime4K 到 2160，再把**整帧**降到 960×540 补帧，最后选择 Anime4K/Jinc/D3D11 输出；原帧细节也会下降。第四项只用半尺寸 RIFE 推理，保留 1080 原帧，再 Anime4K 到 2160。前者的流畅不代表保留了前一级超分细节。4070 Laptop 的指定样本中，Jinc/D3D11 末端达标；另外两项未达标，详见性能台账。

HDR 映射使用上游 RTX TrueHDR，仅允许 D3D11 直通；不兼容路径会提示“请切换到d3d11模式”。详细配置进入渲染/色彩页，实际状态受 NVIDIA 驱动、源格式和 Windows HDR 输出限制；VideoEnhancer 的中灰 22 参数未映射到此接口。

## HLSL 执行与自定义着色器

### Full 内置与 VPY

Full 默认将未修改正文的内置 Anime4K 交给原生 D3D11/HLSL。内置 VPY 仍保留，程序核对正文后再选择路径；手工修改同名文件不会被当成原生模板跳过。HDR、主动启用 libplacebo 色彩处理、先缩放后增强、超过 3840×2160 的滤镜视口等情况继续原 GLSL/VPY，状态栏说明原因。

右键“VapourSynth 预设 → 用户自定义 → 以 HLSL 执行”控制 Full 的优先 HLSL 路径，并记住选择。自定义 VPY 需要同时满足以下条件才能提取 shader：

- 含本项目生成的滤镜图元数据，且实际 Python 正文与该图重新生成的内容一致。
- 只有一个从头到尾的时间组，目标 shader 位于启用处理链的末尾。
- shader 的语法、hook、资源绑定、输出尺寸和色彩路径均在原生执行器的支持范围内。

提取后，前面的滤镜与源读取仍由 VapourSynth 执行，末尾 shader 在 GPU 纹理上运行。原有处理顺序保持不变。中间节点、额外 Python、逐帧回调、时域滤镜和 AI 插件不会被自动翻译成 HLSL；关闭开关或检查失败时继续原 VPY。运行失败也会恢复原 GLSL，并显示原因。

### 导入独立 GLSL/HLSL

在本地视频模式右键打开“自定义 GLSL/HLSL 着色器”：

1. 选择“导入着色器…”，打开 `.hlsl`、`.glsl` 或 `.hook` 文件。
2. `.hlsl` 直接编译；兼容 mpv GLSL 经过 GLSL → SPIR-V → HLSL → D3D11 字节码转换。成功后才切换当前选择。

   本地多通道HLSL支持：同一`.hlsl`可包含多个以`//!HOOK MAIN`或`//!HOOK PREKERNEL`开头的段，使用`//!BIND`、`//!SAVE`、`//!WIDTH`、`//!HEIGHT`等指令描述资源和输出尺寸。每段是独立的`main/ps_5_0` HLSL；播放器逐段编译执行，不能把所有段直接交给单次FXC编译。普通不含HOOK指令的HLSL仍沿用单pass约定。此格式需要包含该续修的播放器。
3. “存储路径（浏览）…”可选择保存目录；默认位于配置文件旁的 `shaders/custom`。导入源按内容标识保存，字节码在该目录的 `cache` 中；已保存源出现在同一菜单。
4. 选择“关闭自定义着色器”恢复普通缩放。底栏与 `Tab` 显示实际生效路径。

图片、音频、网络和 madVR 模式会禁用该导入菜单。直接播放时遇到不兼容的媒体或色彩设置，程序停用该视频的自定义 shader，保留视频播放及导入源；打开下一个文件时重新检查。单文件版没有通用 GLSL 执行后端，转换失败会说明原因，不会将不兼容文件当成成功启用。

缓存按保存的源内容、转换语义版本、转换器及编译器标识校验后复用；内容或工具变化会在下次导入或载入时重新转换，截断或结构损坏的缓存会重建。导入失败保留此前有效的着色器与选择。外部源已复制到存储目录后，修改外部原文件需要重新导入。播放帧不调用 Python 或 Windows SDK；GLSL 导入需要 `runtime/shader-tools` 中的转换组件，缺失时会明确报错。

### 当前支持边界

通用 GLSL 导入支持 `MAIN` / `PREKERNEL` / `LUMA` 的多 pass 像素着色器，以及受支持的 `BIND`、`SAVE`、`WHEN`、`WIDTH`、`HEIGHT`、`COMPONENTS` 语义。按 MAIN → PREKERNEL 阶段执行，各阶段保留文件顺序；覆盖当前 PREKERNEL 图像时不接受显式宽高。中间纹理使用 FP16，`COMPONENTS` 1～4 正确补齐未存储的通道；每份文件最多 128 个 pass、每 pass 最多 8 个纹理绑定。

尺寸表达式支持 `.w/.h`、`.width/.height` 及 `+ - * / > < = !`；`WHEN` 为 0 时跳过对应 pass。`NATIVE` 仅可用于读取原始宽高，不提供其像素采样；依赖被跳过 pass 的纹理等运行时不兼容情况会明确失败。仅支持程序所定义的普通 SDR RGB 路径；HDR、BT.2020/P3 色域、额外显示变换等情况会被拒绝或回退。LUMA hook 先按当前受支持 SDR 矩阵提取亮度，再合回 RGB；不代表支持 CHROMA 或 HDR shader。

`CHROMA` 等未实现 hook、计算着色器、外部纹理、`OFFSET`、`#include` 和不支持的指令不会被忽略。每份文件的实际支持情况以导入检查结果为准，不能仅因扩展名正确或语言编译成功就视为兼容。

原生 HLSL 使用 `main` / `ps_5_0`，可读取浮点 `TEXCOORD0` 和 `SV_Position`，输出为浮点 `SV_Target0`；浮点二维源纹理绑定 `t0`，普通线性 clamp 采样器绑定 `s0`。不支持整数纹理、比较采样器或额外资源布局。最小透传示例：

```hlsl
Texture2D<float4> Source : register(t0);
SamplerState LinearClamp : register(s0);

float4 main(float2 uv : TEXCOORD0) : SV_Target
{
    return Source.SampleLevel(LinearClamp, uv, 0);
}
```

可选常量缓冲 `b0` 必须是总计 32 字节、偏移分别为 0 和 16 的两个 `float4`，可命名为 `sourceSize` 和 `outputSize`，各自 `xy` 为尺寸、`zw` 为其倒数。直接播放的 HLSL 目标尺寸随视频视口决定。需要其它入口、寄存器布局、资源类型或运行时的 HLSL 须先适配接口。

## 音频与主次字幕

底栏音量显示百分比；静音按钮使用话筒图标，带斜线表示静音，静音保留音量数值。静音下方的 EQ 按钮展开均衡器浮层，调节即时生效，点击按钮或浮层外部收起；不打开独立对话框。均衡器与倍速面板只保留一个展开。

右键选择内/外音轨、同步、均衡器及主/次字幕。同目录匹配的音频和字幕可自动加载，其余匹配结果在菜单切换；轨道显示名称、语言和 Default/Forced。

Full 的“AI 实时字幕”使用独立组件。先从下载页面安装 AI-Subtitles，或将完整扩展目录指定到字幕设置，再从右键启用。本轮已准备 Qwen3-ASR-0.6B INT8 CPU 包与真实音频测试；远端列表要等待维护者上传。安装布局、文件与模型来源见 [组件指南](../assets/ai-subtitles/README.md)。识别窗口默认 5 秒，末尾不足一窗也会提交；跳转按 generation 丢弃旧结果。字幕不做翻译，也不保证逐词时间戳精度。

播放视频时，音频拖到画面上半部挂为外部音轨，下半部单独播放；字幕拖到上 40% 挂为次字幕，下 60% 挂为主字幕。通过菜单核对当前选择，避免误加载其它集数。

## 界面与设置

窗口模式底栏位于视频下方；全屏为自动隐藏浮层，约一秒无操作收起，鼠标移到实际底栏区域唤出。顶部可唤出标题和退出全屏按钮。

主题设置分别控制底栏、播放列表与右键/倍速菜单不透明度；新配置底栏与菜单默认 100%。Tab 面板可调整大小，透明度条独立显示，也可启用右侧音频峰值详情。

设置左下角可加载/保存完整 INI。“确定”保存关闭，“应用”保留窗口与播放状态。文件关联页注册格式后，仍需在 Windows 默认应用中选择播放器。

截图/PhotoCraft 见 [截图与图片](capture-images.md)，HDR 与高级输出见 [色彩](color-management.md)，卡顿见 [性能排查](performance-debugging.md)。

## 1.1.0 控制与图片

- 音量条为 0–200%，百分比可编辑；静音、EQ和百分比位于音量条下一行。上下键默认每次5%，滚轮最大100%。EQ再次点击关闭，M再次取消静音，L再次收起播放列表。右键音频处理可打开低延迟动态响度标准化，默认关闭。
- 设置→快捷键集中配置动作、步进和值及开关；默认 `Ctrl+↑/↓` 调倍速，`Ctrl+Shift+←/→` 切章节，`Ctrl+C` 复制当前帧 PNG，`.` 进退极简模式。
- 极简模式只解码音频；音频默认使用该模式，窗口过窄时也自动进入，收为紧凑音频窗口，不显示Tab详细信息。Enter 进入全屏，再按 Enter 回到常规模式；常规音频模式才显示封面与歌词。
- 图片工具栏“缩放、压缩和转换格式”可固定比例或拉伸，选择 Jinc/Lanczos/双线性/最近邻。Full 经 RAW 中间图像交给 AWJ；SDR 非 sRGB 像素先转换到 sRGB，原文件不改写，原 EXIF 不通过 RAW 复制。HDR 使用线性 scRGB FP16 接口。Lite 用 HLSL 重采样并调用外部 FFmpeg 输出。
- 动画 GIF 走视频播放；多页 TIFF 以 100ms/页循环，可暂停，TIFF 不提供 GIF 式逐页时长。
- 页面主题保存在程序旁 `themes.ini`，使用 `VSP-Main`、`VSP-Settings`；默认背景透明度高、亮度低，避免遮住文字。
- 性能页的缓冲池上限只作用于 2160p 及以上软解，Auto 不超过应用内存预算的一半。常规仅按8帧和解码流水线计算预算，不预占内存上限；尖峰前15秒临时扩至最多48帧、2GiB，经过尖峰后缩回小队列。指定GBC第二集本轮按要求不测试。功耗行当前为 N/A，PawnIO 采集和安装尚未接入。
- 单文件首次运行在 EXE 旁解包到本次进程目录，退出后清理；崩溃留下的受控目录在下次启动清理。该位置须可写，FFmpeg shared 仍放在旁边或 PATH。

状态提示显示3秒后隐藏；Tab中的三段缩放算法在同一行，切换到其他窗口后保持显示，再按Tab关闭。
