# Player 操作

## 打开与播放

打开或拖入视频、音频、图片；右键可打开文件夹或网络链接。`Ctrl+O` 打开媒体，`Ctrl+P` 加载 VPY。图片和网络视频不执行 VS 滤镜。

底栏提供播放、逐帧、关键帧、前后文件、时间/帧号输入和倍速。普通视频拖动进度条可预览，松开精确定位并恢复原状态；BD 松开后只提交最终定位，见 [蓝光](bluray.md)。帧号修改后按 Enter 或移开焦点提交。

进退一帧会暂停播放并移动到相邻画面，再按播放可继续；直通模式按当前画面的时间戳定位，长视频无需从头扫描。直接输入绝对帧号在未建立对应索引时仍可能需要较长等待。

| 操作 | 快捷键 / 鼠标 |
| --- | --- |
| 播放/暂停 | `Space` |
| 切换全屏 / 退出全屏 | `Enter` 或 `F11` / `Esc` |
| 输入/输出与运行信息 | `Tab` |
| 短跳转 | `←/→`，默认 ±1 秒，设置中可改帧/关键帧 |
| 较大跳转 | `Ctrl+←/→` 默认 ±10 秒，`Ctrl+Alt+←/→` 默认 ±60 秒 |
| 切换图片 | `←/→`，同目录名称排序 |
| 滚轮 | 视频默认音量，可改鼠标锚定缩放；图片缩放，Shift+滚轮平移 |

## 直通、增强与补帧

D3D11/Jinc 和无预设原画使用 3FP 直通，不建立 VS 索引。Full 右键“图像处理 → 缩放滤镜”提供自动、CNN、no CNN、1X 修复和常规直通共八档；其他缩放算法仅在纯 D3D11 直通中可选，Anime4K/Jinc 固定使用各自链路。Lanczos (3 Taps) / (4 Taps) 位于算法列表末尾。首次增强可能等待索引，手动档位保持所选链路。

原始高度 ≥2160p 时禁用内置 Anime4K，Jinc/D3D11 保持可选。渲染设置完整列出八档，单击选择起始档位、勾选参与自动切换，D3D11 必选；Tab 与底栏显示实际生效链路。自定义 VPY 不受此内置限制，需自行评估资源。

“VapourSynth 预设”只显示用户与社区预设。用户说明来自 Renderer 预设管理的备注；开发者说明由 `vpy/preset-descriptions.json` 的 `builtin/文件名.vpy` 键填写。程序只补缺失的空键，保留已写说明，不内置推荐文案。

Full“图像处理 → 补帧”提供 Jinc/D3D11 自动入口以及 RIFE、RIFE 半宽高、MVTools HQ/LQ 的固定组合。渲染设置用 Jinc/D3D11 两排复选框分别控制自动补帧参与档位；未勾选的档位会跳过，到最后一档仍超载时显示提示。旧配置的补帧起始档位会转换为从该档起参与。关闭补帧后恢复 Anime 自动超分。PlayerLite 只提供原生直通能力。

“超分补帧组合”的前三项先 Anime4K 到 2160，再把**整帧**降到 960×540 补帧，最后选择 Anime4K/Jinc/D3D11 输出；原帧细节也会下降。第四项只用半尺寸 RIFE 推理，保留 1080 原帧，再 Anime4K 到 2160。前者的流畅不代表保留了前一级超分细节。4070 Laptop 的指定样本中，Jinc/D3D11 末端达标；另外两项未达标，详见性能台账。

HDR 映射使用上游 RTX TrueHDR，仅允许 D3D11 直通；不兼容路径会提示“请切换到d3d11模式”。详细配置进入渲染/色彩页，实际状态受 NVIDIA 驱动、源格式和 Windows HDR 输出限制；VideoEnhancer 的中灰 22 参数未映射到此接口。

## 音频与主次字幕

右键选择内/外音轨、同步、均衡器及主/次字幕。同目录匹配的音频和字幕可自动加载，其余匹配结果在菜单切换；轨道显示名称、语言和 Default/Forced。

Full 的“AI 实时字幕”需先在设置→字幕设置设置 SRT 样式、手动下载模型和推理运行时，并指定外置扩展目录；缺失组件会直接打开该页。准备步骤见运行时 `runtime/ai-subtitles/README.md`，源码见 [组件指南](../assets/ai-subtitles/README.md)。模型不随程序分发；运行两次推理后检查 RTF，超过 1 则停止识别并提示。未安装模型的测试不能证明识别质量或实际实时性。

播放视频时，音频拖到画面上半部挂为外部音轨，下半部单独播放；字幕拖到上 40% 挂为次字幕，下 60% 挂为主字幕。通过菜单核对当前选择，避免误加载其它集数。

## 界面与设置

窗口模式底栏位于视频下方；全屏为自动隐藏浮层，约一秒无操作收起，鼠标移到实际底栏区域唤出。顶部可唤出标题和退出全屏按钮。

主题设置分别控制底栏、播放列表与右键/倍速菜单不透明度；新配置底栏与菜单默认 100%。Tab 面板可调整大小，透明度条独立显示，也可启用右侧音频峰值详情。

设置左下角可加载/保存完整 INI。“确定”保存关闭，“应用”保留窗口与播放状态。文件关联页注册格式后，仍需在 Windows 默认应用中选择播放器。
