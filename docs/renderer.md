# Renderer 操作

OpenNGU 放大：添加 GLSL/HLSL 着色器节点，列表第一项为 `OpenNGU-AA-Medium-BestMatch-2x-SDR.glsl`。默认 2×；勾选 HLSL 预览时优先使用同目录对应 HLSL，VS 编码导出始终保留 GLSL。两份源与缓存放在运行目录 `shaders`，适用 BT.709 SDR。

工作台主预览与“图像分析比对”的缩放下拉均可选择“放大：OpenNGU”；悬停可查看限制。该选择用于显示放大，缩小默认回退 D3D11 原生直通；不兼容色彩或缺失模型时放大回退 Jinc。图像分析比对暂不支持以此核导出 VS 画布，会明确提示。

## 项目保护、帧时间组与独立编码（2026-11-10）

时间组同时提供整秒与**源帧号（从0开始）**输入；按帧新建可在同一秒内设置多个边界。CFR秒转换向后吸附到源帧；精确秒数见输入框提示。帧边界写入项目/预设schema 3，老的整秒项目仍可读取。不扩展VFR或VS HDR处理。左下角只保留“精确帧通过源帧号实现”；GLSL滤镜高级参数底部说明“勾选预览使用HLSL加速，导出仍然使用GLSL”。

Ctrl+S保存，Ctrl+Shift+S另存，Ctrl+Z/Y撤销/重做项目状态。关闭或打开另一项目时检查未保存修改；保存采用原子提交并保留上次`.bak`。处理路、时间组、滤镜及可读取VPY正文写入项目；未保存状态约1.2秒生成恢复快照（不是实时零损失保证）。重新启动可恢复上次异常退出快照，不会自动覆盖原项目。未知节点/更新版本明确提示更新并中止载入，避免静默丢节点。

编码现在由同目录 **vs-export-worker.exe** 独立管理vspipe、FFmpeg、管道和冻结脚本。UI退出或崩溃后，已提交任务继续；再次打开导出窗口从持久任务目录重连。关闭窗口提供后台继续/停止/取消。worker异常退出时，正在运行的任务标记中断；只支持明确从头重做，不拼接部分编码。整个系统关机/掉电不能继续编码。

同一源可排不同路任务，常规入队自动在扩展名前追加`_路1`/`_路2`等，冲突再加序号。不覆盖任何输入或已有输出。队列支持暂停、停止、重做及等待任务排序；任务日志保留。任务目录默认`%LOCALAPPDATA%/VSRenderer/export-jobs`，恢复目录为同级`recovery`；测试可通过VSR_EXPORT_ROOT/VSR_RECOVERY_ROOT隔离。命令与路径含私有数据，不应随源码/运行包分发。

构建已增加VSExportWorker目标；分发脚本检查worker存在。仅验证源码构建时可`-DVSR_STAGE_VS_RUNTIME=OFF`跳过本机Python暂存；此开关不意味着已生成可运行发行包。

## 处理视频与时间组

1. 在“VS 实时渲染”打开或拖入源视频，先确认源分辨率、帧率和声音正常。
2. 在滤镜库添加节点，调整顺序、开关和参数；在“参数与脚本”检查生成的 VPY。
3. 默认处理全片；需要分段处理时添加整秒时间组，每组保存独立处理链，可整组复制/粘贴。
4. 播放源/处理后比较。各时间组输出宽高、格式和帧率须一致，避免拼接失败。
5. 保存项目或 VPY 预设，再进行导出。更改增强链后可能需要重新索引和初始化。

四区工作台的两列功能区可分别隐藏。预览下方显示 CPU/GPU/内存及源/输出丢帧；时间与进度条同排，下方提供文件、逐帧、播放、并排和缩放入口。

## 独立处理路与工作文件夹

左侧底部“加路”最多建立三条处理路，各自保存当前时间组、滤镜参数和预设。打开源、加路或载入预设后，各路默认等待，选中该路再点击右上角“渲染预览”才生成输出。两画面时右侧标题为“处理后”，更多处理路时依次为“路1/2/3”。隐藏会卸载该路脚本并停止输出；额外路此前已手动渲染时，显示可恢复已有脚本，第一路隐藏后需重新点击预览。移除后顺序前移，源画面始终保留。默认两画面不变，三画面为三列，四画面为 2×2。底部比较模式在三画面时提供 A/B/C 滑块，四画面时提供 A/B/C/D 滑块；复用 Compare 页的蓝色分界线，所有画面使用同一画布坐标，可拖动交点同时调整横纵分界。

导出先选处理路，加入队列时冻结对应 VPY；预设仍只包含当前一路，“导入到新路”另建一路。项目 JSON schema 2 保存路数组和显示状态，旧单路项目仍可读取。额外路当前执行 VS/GLSL，只有第一路支持现有末尾 HLSL 预览提取。

“工作文件夹”在后台扫描常见视频格式，默认最大深度 3，可在设置中调整；旁边的下拉框切换源。长文件名在下拉列表中自动换行，完整显示；软链接目录不递归。

“NCNN 单帧超分”提供用户现有 VideoEnhancer 包内 21 个超分/降噪模型。仅处理单帧 SDR RGB24；视频或实时 Player 自动跳过。场景识别模型保留在运行资源中，不出现在超分菜单。未将 NCNN 引入实时视频播放。

页面背景按 `VSR-Main`、`VSR-Compare`、`VSR-BDRemux`、`VSR-Settings`、`VSR-About` 分别保存到 `themes.ini`，保存后立即刷新。主界面和比对页面的背景不覆盖视频预览；BD Remux背景可铺满页面，表格保留可读的半透明底色。新增的 QTGMC/SMDegrain 依赖 havsfunc，BM3D/FFT3DFilter 使用已验证的 API4 插件；未把旧 API3 DLL 混入运行目录。

## 多路图像比对与取色

在“图像分析比对”导入图片或视频，选择并排、滑块或网格布局；AVIF 可直接拖入。缩放后按住左键平移，“同步缩放”控制各路视图，滑块布局始终共用画布。

滚轮缩放不再受固定 1600% 上限限制，大倍率仅绘制视口内的区域；保留渲染坐标数值范围的保护，避免溢出。百分比相对于各路的适应窗口尺寸，不同源尺寸下不代表相同的源像素放大倍数。

鼠标指向一路时，各路一起显示对应的**源像素坐标**与颜色值；即使窗口尺寸不同，也比较同一源坐标。“颜色处理”左边的“颜色显示”默认 RGB，可切换 YUV。

- **RGB**：渲染输出的码值，受颜色处理、缩放、输出位深与显示映射影响。
- **YUV**：解码源的原始 Y/U/V 码值，标出原位深；4:2:0/4:2:2 直接读取该像素所属的色度样本，不由 RGB 反算。不同位深的数字范围不同。
- 超出其他源尺寸、RGB 对应点不在其视口或源本身没有 YUV 时会明确提示，不用边缘像素或换算值替代。

## 本地与社区预设

“预设管理”保存/加载处理链，目录树保留子目录。预设可携带全部时间组；全片单组预设可导入当前组。外部普通 VPY 可执行，但不保证能还原成可编辑的图形节点。

下载失败时检查源地址、网络及组件提示；不要把公开页面地址手工替换为临时下载链接。

mpv GLSL 节点可按功能分类、名称搜索或加载兼容 `.glsl`。输出支持倍率或指定尺寸，“保持宽高比”使宽高联动；悬停查看完整路径和要求。RIFE 需要有效 NCNN 模型与 Vulkan 驱动。

## GLSL 节点的 HLSL 预览

1.0.17 起，mpv GLSL 节点的“高级参数 → 以 HLSL 执行”默认开启。渲染预览时，兼容的末尾 shader 可从 VPY 中取出，在前序滤镜输出的 GPU 纹理上由 D3D11 执行。右侧画面显示 `VS + HLSL`，状态栏保留不兼容原因。

预览根据前序滤镜的实际输出尺寸计算倍率、指定宽高和保持比例参数，再传给 shader 的 `OUTPUT`；不会用预览窗口尺寸替换节点所要求的处理尺寸。当前 native 目的矩形保持源比例，因此指定不同比例的输出、超出 D3D11 尺寸范围等情况保留原 GLSL。

以下情况继续原 VPY/GLSL：

- shader 后仍有启用滤镜，或存在多个时间组，无法在保持原顺序的前提下提取。
- 导入的 VPY 含额外 Python、修改过生成正文或不含可验证元数据。
- shader 使用尚未实现的 hook、指令、计算或外部纹理等功能。
- HDR、BT.2020/P3 色域、额外显示变换或其它不兼容色彩路径，以及 native 运行失败。

支持范围为 [Player 指南中的通用着色器子集](player.md#当前支持边界)。多个 shader 节点串联时，仅兼容的末尾节点可提取，前序节点仍在原链中执行。该方式并未把整份 VPY 编译为 HLSL；任意 Python、第三方插件、逐帧决策、时域处理与 AI 推理都需要对应的执行实现。

**此开关只影响渲染预览。** “生成的 VapourSynth 脚本”、预设和编码导出保留完整 VPY/GLSL 处理链，不导出独立 HLSL 或以 HLSL 编码视频。HLSL 的运行位置位于原生色彩处理后的 RGB 阶段，不能据语言转换成功声称与任意 libplacebo/HDR 链逐像素等价；涉及颜色或顺序差异时采用回退路径。

## 多视频比对

切到“图像分析比对”，导入多个源，选择并排/网格/滑块布局；分别调整时间偏移、视频来源与音频来源。滚轮缩放，放大后拖动画面。

“导出对比画布…”支持 AB 滑块、ABC 左右 2+1、ABCD 常规/滑块 2×2；其它布局按界面提示处理。实时预览与离线合成不保证逐像素等价。

## 编码导出

打开导出窗口，粘贴 3FUI FFmpeg 命令，保留输入/输出位置并选择 MKV 输出，加入编码队列。批量输入先加入“准备文件”，再统一排队。

也可将 `plugins/3FUI/VsrExportBridge.3fui.dll` 复制到 3FUI 的 `plugin` 目录，由用户重启宿主加载；先打开 Renderer 导出窗口，再点击插件发送当前参数面板命令。接收只填入命令并保存历史，不启动编码；可保存或调用历史命令。构建与宿主边界见 [插件说明](../plugins/3fui-export-bridge/README.md)。

队列支持暂停/恢复、移除等待项、停止保留输出及从头重做。导出前检查冻结的源、滤镜、尺寸和音轨/字幕/章节映射；不要将输出指向原文件。具体编码器必须由当前 FFmpeg 提供。

缺少 namespace 或模型时按 [构建指南](dependencies.md) 检查运行时；播放卡顿按 [性能排查](performance-debugging.md) 区分索引与稳定吞吐。

## 1.1.0 基础修正

搜索框下选择滤镜类型；关键词仅在该类型内匹配。“加路、减路、显示、隐藏”在同一行，开启同步视图后从任意一路缩放或平移会联动全部处理路。

视频输入右侧可导入文件夹，递归深度默认3并可在设置调整；导入后输入框变为视频下拉列表。支持拖入文件夹。

mpv GLSL/HLSL共用节点和自定义入口；“以HLSL执行”位于保持宽高比下面。GLSL保留VS编码导出，原生HLSL作为末尾节点用于各处理路的D3D11预览；不能直接交给libplacebo执行或导出为VS编码链。不支持的执行语义明确报错。

可用 `python tools/precompile-shader-library.py --compiler build/mingw-release/vsr_shader_precompile.exe --source assets/mpv-shaders --output .deps/compiled-shaders110` 离线编译逐个文件；每文件默认限30秒，失败与超时保留在shader-batch-report.json，成功包包含源哈希与语义标记。离线编译不等于实际画面验证。

本轮离线库为266/915份可编译包，其中35份为本轮补齐；其余649份仍不兼容（包含计算pass、OFFSET、CHROMA/NATIVE阶段、超过8纹理绑定等），不作为可用HLSL打包。未进行新增shader的实际像素验证。
