# Renderer 操作

## 处理视频与时间组

1. 在“VS 实时渲染”打开或拖入源视频，先确认源分辨率、帧率和声音正常。
2. 在滤镜库添加节点，调整顺序、开关和参数；在“参数与脚本”检查生成的 VPY。
3. 默认处理全片；需要分段处理时添加整秒时间组，每组保存独立处理链，可整组复制/粘贴。
4. 播放源/处理后比较。各时间组输出宽高、格式和帧率须一致，避免拼接失败。
5. 保存项目或 VPY 预设，再进行导出。更改增强链后可能需要重新索引和初始化。

四区工作台的两列功能区可分别隐藏。预览下方显示 CPU/GPU/内存及源/输出丢帧；时间与进度条同排，下方提供文件、逐帧、播放、并排和缩放入口。

## 本地与社区预设

“预设管理”保存/加载处理链，目录树保留子目录。预设可携带全部时间组；全片单组预设可导入当前组。外部普通 VPY 可执行，但不保证能还原成可编辑的图形节点。

社区入口按目录浏览和下载，设置中的下载源使用 VS-GUI 的公开页面地址：

[VS-GUI 预设社区](https://www.modelscope.cn/datasets/ARXChem/Software-List/tree/master/VS-GUI/PresetCommunity)

下载失败时检查源地址、网络及组件提示；不要把公开页面地址手工替换为临时下载链接。

mpv GLSL 节点可按功能分类、名称搜索或加载兼容 `.glsl`。输出支持倍率或指定尺寸，“保持宽高比”使宽高联动；悬停查看完整路径和要求。RIFE 需要有效 NCNN 模型与 Vulkan 驱动。

## 多视频比对

切到“图像分析比对”，导入多个源，选择并排/网格/滑块布局；分别调整时间偏移、视频来源与音频来源。滚轮缩放，放大后拖动画面。

“导出对比画布…”支持 AB 滑块、ABC 左右 2+1、ABCD 常规/滑块 2×2；其它布局按界面提示处理。实时预览与离线合成不保证逐像素等价。

## 编码导出

打开导出窗口，粘贴 3FUI FFmpeg 命令，保留输入/输出位置并选择 MKV 输出，加入编码队列。批量输入先加入“准备文件”，再统一排队。

也可将 `plugins/3FUI/VsrExportBridge.3fui.dll` 复制到 3FUI 的 `plugin` 目录，由用户重启宿主加载；先打开 Renderer 导出窗口，再点击插件发送当前参数面板命令。接收只填入命令并保存历史，不启动编码；可保存或调用历史命令。构建与宿主边界见 [插件说明](../plugins/3fui-export-bridge/README.md)。

队列支持暂停/恢复、移除等待项、停止保留输出及从头重做。导出前检查冻结的源、滤镜、尺寸和音轨/字幕/章节映射；不要将输出指向原文件。具体编码器必须由当前 FFmpeg 提供。

缺少 namespace 或模型时按 [构建指南](dependencies.md) 检查运行时；播放卡顿按 [性能排查](performance-debugging.md) 区分索引与稳定吞吐。

## 设置与关于

设置页按源模式、语言/主题、社区源、组件更新顺序滚动展示，主题切换即时生效，包含高级参数的背景、输入控件和文字。工具栏“关于”显示程序版本、the VS-GUI Project (MIT) 与作者。
