## 未关闭的验收问题

- 原生BT.2020 CL与NCL未区分，color-final.txt为9通过/1失败；可选libplacebo路径的区别测试通过。
- Full连续测试仍有浮层额外redraw与音频Tab面板布局失败。此前码率探测在对象销毁后回调导致异常退出，已补销毁前停止/断开回调；最终Full整套在越过旧崩溃位置后，仍在大图测试附近异常退出（exit 3221225477），stderr出现vkAllocateMemory -2 / vkWaitForFences -4，不能据此确认根因；另有9个断言失败，见player-shutdown-fixed.txt。不能从单项退出成功推断整套通过。
- Renderer全套发生社区示例下载失败、帧控件居中断言失败，并在180秒截止时未完成；独立处理路专项通过不关闭这些问题。
- 原始25组CTest完成时20组通过/5组失败（两组异常退出）；后续修复仅由同路径重测关闭，不改写原始结果。PhotoCraft最后专项5通过/0失败/1跳过，大图1.536Gpixel样本未提供；Lite最后37通过/0失败/5跳过。
- 无GBC第二集尖峰、780M/7840HS、NuxBox、真实IAMF听感等新验收证据。
