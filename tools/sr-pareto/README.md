# 超分算法 Pareto 图模板

本地 HTML 模板：横轴为 **1–10000 原始算力值的对数刻度**，纵轴为效果值，点旁显示模型或算法名称。默认算力越低越好、效果越高越好，自动绘制 Pareto 阶梯线。算法名称与数值由同目录 `algorithms.json` 提供，模板不验证其测量依据。Preview 模型不参与前沿计算，可选择隐藏。

## 使用

1. 编辑 `algorithms.json`。
2. 双击 `index.html`，点击“打开 JSON”选择编辑后的文件。
3. 修改 JSON 后点击“重新读取”；若浏览器无法重新读取文件或仍显示旧值，再次“打开 JSON”选择同一文件。

无需安装依赖、无需联网，数据在浏览器本地处理。请保留整个文件夹，HTML 依赖同目录的 JS/CSS。

若希望页面打开时自动读取 JSON，在此目录运行：

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

浏览器访问 <http://127.0.0.1:8766>。编辑保存 JSON 后点击“重新读取”即可更新，`Ctrl+C` 停止服务器。

## JSON 格式

```json
{
  "title": "超分质量与算力比较",
  "description": "填写测试设备、素材、缩放倍率与指标等背景",
  "xLabel": "处理算力要求（原始值 · 对数刻度）",
  "yLabel": "处理效果（评分）",
  "yMin": 0,
  "yMax": 100,
  "algorithms": [
    { "name": "算法 A", "compute": 10, "quality": 55, "group": "着色器" },
    { "name": "模型 B", "compute": 500, "quality": 82, "group": "神经网络" }
  ]
}
```

| 字段 | 含义 |
| --- | --- |
| `algorithms` | 必填数组，可为空；每个对象绘制一个点 |
| `name` | 必填，显示的算法或模型全名 |
| `compute` | 必填数值，范围 1–10000，可为小数；填写原始值，不要预先取对数 |
| `quality` | 必填有限数值，越高越好；可使用评分、PSNR、SSIM 等同一指标 |
| `group` | 可选，同组同色；省略时归入“未分组” |
| `preview` | 可选布尔值，默认 `false`；`true` 表示预览阶段，不参与前沿计算及名单 |
| `title` / `description` | 可选，图表标题与数据说明 |
| `xLabel` / `yLabel` | 可选，坐标轴名称及单位 |
| `yMin` / `yMax` | 可选，纵轴范围；省略时按数据自动适配。范围必须覆盖全部数据 |

所有点应来自相同的测试条件和同一效果指标。使用 LPIPS 等“越低越好”的指标时，请先转成“越高越好”的效果值，并在 `yLabel` 中写明转换。图表不会自动评估算法，也不会把不同效果指标混合。

## 前沿规则与显示

- 在算法对象中添加 `"preview": true` 即可标为预览阶段；例如 `{ "name": "MoE-IR-Zenith", "compute": 300, "quality": 85, "group": "轻量超分模型", "preview": true }`。当前四个 MoE-IR 模型已标记。正式发布后改为 `false` 或删除该字段。
- Preview 默认显示，标签附带 `(Preview)`，点使用虚线边框。勾选“隐藏 Preview 模型”后隐藏；显示与隐藏都不改变正式算法的前沿和名单，Preview 也不会挤掉正式算法。
- 若另一个算法的算力不更高、效果不更差，且至少有一项严格更优，当前点就不在前沿上。
- 相同算力只保留最高效果进入前沿；相同效果只保留最低算力。完全相同坐标的点都属于前沿，图上重合，右侧名单保留每个名称。
- 阶梯线在相邻前沿点之间保持此前最佳效果，不表示两种算法之间存在连续实测结果。
- 鼠标停留在点上可查看名称、原始算力和效果，键盘 `Tab` 聚焦点时也有可访问说明。名称可通过复选框隐藏。
- 窄屏可横向滚动图表，以保持名称可读。密集数据会尽量避让标签，但无法保证任意数量或超长名称都不重叠。
- JSON 无效时显示具体错误并保留上次有效图表；不会静默丢弃错误点。

## 文件与检查

`index.html` 为入口，`style.css` 为深色布局，`app.js` 负责文件读取与 SVG 绘制，`data.js` 负责校验、对数映射和前沿计算，`algorithms.json` 为数据源。运行 `node --test data.test.cjs` 检查数学与输入边界。

视觉参考：[Paraplouis/llm-pareto-frontier](https://github.com/Paraplouis/llm-pareto-frontier) 及用户提供的图例；本模板独立实现，不依赖该项目代码或在线数据。
