    如何替换数据

    编辑同目录的 algorithms.json，填写 name（名称）、compute（1–10000 的原始算力值）、quality（效果值）。group 为可选分组。双击打开本页后，点击“打开 JSON”选择文件；通过 HTTP 访问时会自动读取同目录 JSON。

    修改文件后点击“重新读取”；若浏览器无法再次读取已选文件，请重新选择。所有数据仅在本地浏览器中处理。
