`I1.png` / `I2.png` 为生成透明缺口异常的试稿，仅保留原图，不生成 ICO，不作为推荐候选。应用图标仍是 AI 原始设计，复杂方案缩到 16px 会损失细节；用户选型后可进一步精简轮廓和修整边缘。

`ico/` 为上述八款的候选 ICO，含 16、20、24、32、40、48、64、96、128、256 像素，均为32位；检查 ICO 文件头、目录尺寸 / 位深 / 偏移、十档解码和透明通道通过。没有进行 Windows Shell 集成测试。重做转换可运行 `convert_ico.py`（需要 Pillow），提示词与原始输出路径完整保存在 `prompts.json`。
